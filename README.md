# Moosung Kim — Research Website

A one-page academic profile for conference introductions and research networking.

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Checks

```bash
npm run lint
npm test
```

## Main files

- `app/page.tsx` — profile and research content
- `app/globals.css` — visual system and responsive layout
- `app/layout.tsx` — page metadata and social-preview settings
- `public/moosung-kim-og.png` — social-preview card
